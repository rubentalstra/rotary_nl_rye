# Changelog

All notable changes to Rotary YEP NL are recorded here. The format follows
[Keep a Changelog 1.1.0](https://keepachangelog.com/en/1.1.0/) and the app
follows [Semantic Versioning](https://semver.org/). Changes since the last
release wait as fragments in `changelog.d/` until the release cut writes them
here (`bash scripts/release/changelog.sh --assemble X.Y.Z YYYY-MM-DD`).

Versions up to 13.2.1 were the React Native app, archived in `archive/`; their
history is in git and in the GitHub releases. 14.0.0 is the first native
release.
