# Archive: the React Native app (v13)

The Expo SDK 58 app that shipped as versions 13.x on the App Store and Google
Play, frozen on 2026-11-13 when the native rewrite started. It is kept as a
reference for what each screen did and for its content (`src/features/*/data/*.json`,
`src/lib/i18n/locales/`, `assets/`).

- Nothing here is built, linted or released. Do not edit it.
- The native apps never import from it. Copy what a native screen needs
  (content, images) into `ios/` or `android/`, and convert it there.
- `AGENTS.v13.md` and `CLAUDE.v13.md` here are the instructions of the old app and do
  not apply to the repository. The root `CLAUDE.md` does.
